🚀 Features

- 🟩 Set Start Node (Green cell)  
- 🟦 Set End Node (Blue cell)  
- ⬛ Random Wall Generation**  
- 🟧 Shortest Path Display using *Dijkstra Algorithm*  
- 🎛️ Fully interactive grid (click to add/remove walls)  
- 📱 Responsive fullscreen grid
